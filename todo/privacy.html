このツールについて

「やることリスト」は、開発者本人が使う個人用ツールです。ほかの人に提供するサービスではありません。

利用するGoogleのデータ

このツールは、Google Calendar API を通じて次のことだけを行います。

  • 本人がDiscordの自分用チャンネルに書いたメモのうち、日付を含むものを、本人のGoogleカレンダー（既定のカレンダー）に終日予定として作成する
  • 連携の設定時に一度だけ、連携先のカレンダーの名前を確認する

カレンダーにある既存の予定を読み取ったり、変更・削除したりすることはありません。

データの保存と共有

  • Googleから受け取る認証情報のうち、リフレッシュトークンは、本人の非公開のGitHubリポジトリに暗号化されたシークレットとしてだけ保存します。アクセストークンは実行中に一時的に使うだけで、保存しません
  • 作成した予定の記録（日付・タイトル・元のメモ）は、本人の非公開のGitHubリポジトリに保存します
  • メモに日付が含まれるかを判定するため、メモの本文を Anthropic の Claude API に送ります。Googleから受け取ったデータは送りません
  • Googleから受け取ったデータを外部のサーバーに送ったり、第三者に提供・販売したりすることはありません
  • 広告や分析の目的では使いません

連携の解除

Googleアカウントのサードパーティ製のアプリとサービスから、いつでも連携を解除できます。

このツールによるGoogle APIから受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
