このツールについて

「YouTube自動投稿」は、開発者本人が自分のPCで使う個人用ツールです。ほかの人に提供するサービスではありません。

利用するGoogleのデータ

このツールは、YouTube Data API を通じて次のことだけを行います。

  • 本人の録画ファイルを、本人のYouTubeチャンネルに非公開でアップロードする
  • 本人のチャンネルにある再生リストの一覧を取得し、必要なら再生リストを作って動画を追加する
  • 連携先のチャンネル名を確認する

データの保存と共有

  • Googleから受け取る認証情報（アクセストークン）は、本人のPC内のファイルにだけ保存します
  • 取得したデータを外部のサーバーに送ったり、第三者に提供・販売したりすることはありません
  • 広告や分析の目的では使いません

連携の解除

Googleアカウントのサードパーティ製のアプリとサービスから、いつでも連携を解除できます。

このツールによるGoogle APIから受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
